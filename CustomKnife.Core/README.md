# CustomKnife.Core

Версия `0.2.0` хранит каталог ножей в PostgreSQL-схеме `custom_knife` и
поддерживает полное управление через Game CMS.

## Каталог

Таблица `custom_knife.knives` содержит внутренний ID, название, описание,
модель, скорость, гравитацию, множитель урона, оба параметра отбрасывания,
состояние, порядок и необязательный `required_permission`.

Каталог автоматически перечитывается при запуске плагина и один раз при каждой
загрузке карты. Периодический polling отсутствует. Замена runtime-снимка
атомарна: при недоступной БД или некорректной активной записи продолжает
работать последний успешный снимок. Немедленное обновление можно запустить из
серверной консоли:

```text
custom_knife_reload
```

## Доступ через Admin.Core

`required_permission` содержит ключ из `admin.permissions`. Пустое значение
открывает нож всем игрокам. Нож с указанным ключом нельзя выбрать или
использовать без `IAdminApi.HasPermission`.

При загрузке карты выбранные ножи проверяются повторно. Проверка также
выполняется при выборе, спавне и штатной выдаче ножа. Если разрешение отозвано,
нож выключен либо удалён, сохранённый выбор меняется на `knife_axe`, а игроку
выдаётся стартовый дефолтный нож. Дефолтный fallback доступен даже при
недоступной БД или Admin.Core.
