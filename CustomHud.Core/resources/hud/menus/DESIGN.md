# Общий HUD меню Elysium

Ресурсы `elysium_menu_v4.xml` и `elysium_menu_v4.css` используются сервером и
превью Flute CMS. Изменения этих файлов копируются в
`app/Modules/ElysiumMapRotation/Resources/panorama/panorama/` репозитория CMS.
`elysium_map_rotation_v4.css` — резервная тема; CMS экспортирует свой вариант
из `Resources/menu-theme.css` с выбранным оформлением.

## Геометрия

По умолчанию масштаб составляет 80%; доступны 100% и 120%. На горизонтальном
экране шесть карточек имеют ширину около 220 px при масштабе 100% и рамке
1448 px. Рамка ограничена 94% доступной ширины, а при масштабе 120% —
78,333333% до масштабирования. Карточки пропорционально сужаются на 4:3.

Голосование содержит максимум шесть карт: один горизонтальный ряд либо шесть
вертикальных строк. Номинации от семи до двенадцати карт занимают два ряда
горизонтально и два столбца вертикально. Сервер распределяет восемь карт по
вертикальным слотам `0..3` и `6..9`, десять — `0..4` и `6..10`.

Блок `ItemsViewport` сохраняет размеры на последней странице. `PageItemsN`
обозначает вместимость, а не оставшееся количество карт. `Hidden` убирает
пустые карточки; `HasSecondRow` остаётся активным до смены каталога. Переход
меняет `transform` и `opacity` внутреннего `Items`. Настройки находятся вне
`MenuFrame`, поэтому открытие настроек не расширяет и не пересобирает окно.

Вертикальный промежуток между карточками — 12 px, между рядами горизонтальной
номинации — 20 px. Отключённые подзаголовок и футер скрываются вместе со своими
отступами. Иконки шестерёнки и бренда уменьшены и приглушены через opacity.

Кружок с галочкой существует визуально только на `.Selected .SelectedCircle`.
У остальных карточек нет пустых кружков. Название — переведённый заголовок,
описание — исходное имя карты. Длинные строки обрезаются многоточием; текст
не выходит за рамки изображения или соседней карточки.

## Состояния и контракт

- Адресуемый `MenuRoot` находится внутри корневого `Panel` без `id`.
- Общие классы: `Visible`, `Modal`, `MapRotation`, `List`, `Nomination`, `Vote`,
  `Compact`, `Result`, `HasBrand`, `HasSettings`, `HasParticipation`,
  `SettingsOpen`, `Horizontal` / `Vertical`, `Scale80` / `Scale100` / `Scale120`,
  `DockLeft` / `DockRight`, `AnimationNone` / `AnimationFast` /
  `AnimationNormal` / `AnimationSlow`.
- `Row0` содержит `Item0..5`, `Row1` — `Item6..11`. Каждая карточка содержит
  `ImageN`, `NameN`, `DescriptionN`, `BadgeN`, `BarN`.
- Классы карточки: `Selected`, `Disabled`, `Hidden`, `HasBadge`, `HasProgress`.
  `BarN` получает ровно один класс `Pct0..100`; сервер не передаёт SetStyle.
- Тексты заголовка, подзаголовка, счётчика, пагинации, футера и настроек —
  `{s:value}`. XML содержит только бренд и технические знаки. Runtime получает
  строки из `Localization.Api.ILocalizationApi`.
- Кнопки: `Gear`, `SettingsClose`, `Close`, `Back`, `PreviousPage`, `NextPage`,
  `SetHorizontal`, `SetVertical`, `SetScale80/100/120`, `SetDockLeft/Right`,
  `SetAnimationNone/Fast/Normal/Slow`. Подписи последних кнопок имеют суффикс
  `Text`. `DockSettings` и `AnimationSettings` скрываются при отсутствии подписей.

Закрытие голосования запускает `Minimizing`: сдвиг к выбранной стороне,
уменьшение и исчезновение. После перехода тот же runtime получает `Compact`,
показывает все шесть результатов и освобождает захват ввода. Игрок возвращается
в полное голосование командой `!rtv` либо назначенной серверной кнопкой.
`Result` заменяет компактную панель карточкой победителя на той же стороне.
Счётчик результата фиксирует финальную статистику, затем результат скрывается
по таймеру сервера; значение по умолчанию — шесть секунд.

Смена страницы использует `PageLeavingNext/Previous`, затем
`PageEnteringNext/Previous`. При семантической перестановке карточек сервер
готовит скрытую сущность, оставляя старый кадр видимым до замены. Это исключает
применение запоздалого клика к другой карте. Обычный выбор, обновление голосов
и открытие настроек не пересоздают сущность. `EntranceAnimated` устанавливается
только при первом открытии; скрытая замена страницы не воспроизводит анимацию
всего окна. Период перехода: 0 / 140 / 240 / 380 мс.

## Изображения и проверка

В XML используются скомпилированные ресурсы `.vsvg`; в VPK должны находиться
`.vsvg_c`. Картинки карт передаются классами экспортируемой темы с URL на
`.vtex`; PNG исходник компилируется Workshop Tools. Для небольших превью
достаточно PNG 512 × 320 либо 640 × 400, с крупными формами, мягким контрастом,
без надписей и мелких деталей. Увеличение разрешения не упрощает изображение.

Статическая проверка: `python3 scripts/validate-menu-resources.py`. Она проверяет
дерево, привязки 12 слотов, допустимые типы панелей и классы прогресса. Превью
браузера адаптирует общие XML/CSS, но не является рендером Panorama. Требуется
отдельно собрать ресурсы актуальными CS2 Workshop Tools и проверить в игре
16:9 и 4:3, масштабы 80/100/120, обе раскладки, длинные переводы, закрытые
картинки/подзаголовок, вторую и последнюю страницы, настройки, компактное
голосование и итог. Здесь компиляция CS2 не выполнялась.
