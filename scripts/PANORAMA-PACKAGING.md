# Отдельный архив Panorama

Workflow `Build` после успешной сборки и .NET-тестов запускает проверки упаковщика,
затем шаг `Package Panorama resources`. Отдельный артефакт `Elysium.Panorama.Release.zip`
публикуется шагом `Upload Panorama resources` рядом с архивами runtime и документации
и хранится 14 дней. Скачивание доступно в Actions → Build → нужный запуск → Artifacts

Используется `actions/upload-artifact@v7` с `archive: false`: загружается готовый ZIP,
без дополнительного ZIP-контейнера. Имя артефакта совпадает с именем файла

## Содержимое

```text
Elysium.Panorama.Release.zip
├── panorama/
│   ├── layout/...
│   ├── styles/...
│   ├── images/...
│   └── ...
└── panorama-manifest.json
```

Все найденные исходные папки `panorama` объединяются в одну, с сохранением путей
внутри них. Например, `Shop.Core/resources/hud/shop/content/panorama/layout/custom_game/x.xml`
становится `panorama/layout/custom_game/x.xml`. Добавление нового HUD не требует
изменения workflow или списка плагинов. Фильтра по расширениям нет

Каталоги сборки и зависимостей (`bin`, `obj`, `artifacts`, `dist`, `output` и другие,
перечисленные в `EXCLUDED_DIRECTORIES`) исключены из поиска корней, чтобы не собирать
старые копии ресурсов. Внутри найденной `panorama` файлы не фильтруются по этим именам

Совпадающие пути с одинаковым содержимым включаются один раз. Разное содержимое,
конфликт регистра имён, конфликт файла с каталогом, символические ссылки в ресурсах,
ошибки чтения и отсутствие ресурсов завершают упаковку с ошибкой. Старый ZIP удаляется
перед повторной упаковкой, новый публикуется только после проверки целостности

Манифест содержит исходные пути, размер и SHA-256 каждого файла. Даты записей ZIP
фиксированы, поэтому одинаковые входные файлы дают одинаковый архив в одном окружении

## Локальный запуск

Требуется Python 3.10 или новее, сторонних Python-пакетов нет

```bash
python3 scripts/package-panorama.py --configuration Release
python3 -m unittest discover -s scripts/tests -p 'test_package_panorama.py' -v
```

На Windows можно использовать `py -3` вместо `python3`

Результат: `dist/Release/panorama/Elysium.Panorama.Release.zip`
Для Debug укажите `--configuration Debug`. Упаковщик можно вызвать из любого каталога,
корень репозитория по умолчанию определяется относительно самого скрипта

Существующие `build-package.ps1`, `package.ps1` и архивы плагинов не меняются:
локально Panorama упаковывается отдельной командой, в CI — отдельным шагом

## Это не компиляция ресурсов

Скрипт упаковывает только уже существующие файлы, не запускает генераторы, Workshop Tools,
`resourcecompiler` и не создаёт VPK. XML/CSS/SVG не превращаются в `vxml_c`, `vcss_c`,
`vsvg_c`. Уже присутствующие скомпилированные файлы сохраняются без преобразований

Для текущих исходных HUD папка `panorama` предназначена для копирования в
`content/csgo_addons/<addon>/` перед компиляцией Workshop Tools. Манифест в аддон
копировать не требуется. Исходники нельзя просто положить на сервер вместо
скомпилированных ресурсов. Если в архиве есть готовые бинарные ресурсы, их исходные
корни указаны в манифесте; размещайте их в соответствующем game-каталоге отдельно
