# Баннеры, Localization и роли

Обновление: CustomHud.Core 1.3.0, Advertisement.Core 3.1.0, Localization.Core 1.7.0, Admin.Core 0.2.0, ZombiePlague.Core 0.6.0

## Установка вместе с ресурсами

Обновите все пять плагинов из одного runtime ZIP и три модуля сайта: ElysiumAdvertisements, ElysiumLocalization, ElysiumAdmins
Admin и Advertisement применяют миграции при запуске

Скопируйте оба каталога `content/panorama` из ресурсов CustomHud.Core и ZombiePlague.Core в content своего аддона Workshop Tools и скомпилируйте XML, CSS и все SVG
В VPK должны попасть:

- `panorama/layout/custom_game/elysium_messages_v4_r2.vxml_c` и `panorama/styles/custom_game/elysium_messages_v4_r2.vcss_c`
- `panorama/layout/custom_game/elysium_ability_buffs_v4_r2.vxml_c` и `panorama/styles/custom_game/elysium_ability_buffs_v4_r2.vcss_c`
- Все 12 `panorama/images/custom_game/elysium/banners/*.vsvg_c` и 8 `panorama/images/custom_game/elysium/abilities/*.vsvg_c`

Пути Image используют `s2r://panorama/images/…/*.vsvg` — скомпилированные векторы, а не исходный SVG
Это новая ревизия поддерживаемого v4, не возврат к v1
Старый VPK с `elysium_messages_v4` несовместим с новым пулом карточек: проверка наличия ресурсов остановит HUD и перечислит отсутствующие файлы
Доставьте один и тот же VPK серверу и клиентам, перезапустите клиент и смените карту
Проверьте `custom_hud status`, `custom_hud test TopCenter`, `zp_ability_hud debug`
Компиляция VPK и проверка фактической отрисовки требуют Workshop Tools и CS2, они не выполняются .NET CI

## Одновременные уведомления

В **Реклама → Баннеры → Плагины → нужное событие** поле «Повторные события» предлагает:

- `queue` — последовательность с полной длительностью каждого сообщения
- `replace` — обновление текущего сообщения без повторного звука и появления
- `stack` — до трёх карточек друг под другом, остальные ждут освобождения места

Стопка учитывает обычный баннер в той же области: с ним остаются два дополнительных места
У каждой карточки своя длительность и анимация исчезновения, перестановка не повторяет звук
Очередь ограничена 32 ожидающими событиями на игрока, учитывает максимальное время ожидания, приоритет, cooldown и смену SteamID в слоте
Для прямого Custom HUD API задайте `HudMessageOptions.Stack = true`; при заполненной области `Show` вернёт false, плагин может повторить отправку позже
`Hide`/`ClearChannel` удаляют все экземпляры своего канала

Стандартные информационные события теперь используют стопку
`Game.Round.Started` остаётся сверху по центру с приоритетом 300, первое заражение и выбор особого игрока — компактно справа
Миграция меняет только полностью совпадающие с прежними начальными значениями записи; пользовательские настройки не перезаписываются
Если событие уже настроено вручную, выберите позицию/приоритет/стопку самостоятельно

Каждая используемая область создаёт одну сущность Custom HUD с тремя карточками — 239 panel IDs вместо превышения лимита 1024 в общем макете
Захват ввода выключен, меню остаётся независимым
Ширина текстовой области задаётся явно и рассчитывается одинаково на сервере и в Preview

## HTML и цвета ролей

Localization поддерживает `b`, `strong`, `i`, `em`, `u`, `br`, `font color` и `span style="color:…"`
Ссылки, картинки, произвольные атрибуты и CSS в тексте не разрешены
Режимы Preview: «Теги», «Чат», «HTML»
Чат ограничен своей палитрой и не показывает HTML-начертания, HTML сохраняет цвет и b/i/u
Старые цветовые коды Localization также преобразуются для HUD
Явный цвет перевода имеет приоритет над цветом текстового блока шаблона
Цвет параметра в конструкторе по умолчанию `inherit`; если выбрать другой, он намеренно перекрасит параметры

Пример перевода: `{role_color}<b>{player}</b>{/role_color} — раунд {round}: {roundName}`
Альтернативы: `{color:role}текст{/color}`, `<font color="role">текст</font>`
`role_color` определяется **активной ролью получателя**, а не по имени произвольного участника в параметре
`{role_key}` и `{role_name}` доступны в уведомлениях; каталог содержит 57 параметров и алиасы

В ElysiumAdmins у роли задаются цвет чата, HTML-цвет #RRGGBB и приоритет оформления 0–1000
Выбирается активная роль с максимальным приоритетом, при равенстве — первая по ключу
Без роли используются стандартный чат и белый HTML; первоначальные административные роли получают красный
Эти настройки не изменяют права или срок действия роли, читаются через Admin API из памяти
Изменения загружаются штатным механизмом обновления Admin, при недоступности Admin API используются обычные цвета

Плагины передают исходные типизированные параметры в новый `FormatForPlayer(..., LocalizationOutputMode.Html)` либо `ICustomBannerApi.ShowLocalized`
Строки экранируются один раз после проверки типов; ник не может вставить HTML или цветовые управляющие коды
Старые перегрузки Localization сохраняют прежний контракт

## Preview и эффекты

По умолчанию экран 1920 × 1080; доступны HD, QHD, 4K, 4:3, 5:4, 16:10, Ultrawide и собственный размер
Выбор запоминается в браузере и не попадает в настройки доставки рекламы
Как в Panorama, координаты масштабируются от высоты 1080
Preview показывает геометрию и ограничения строк; шрифт Stratum2, safe zone клиента и растягивание 4:3 могут давать отличия от браузера

Появление/исчезновение: fade, slide_up/down/left/right, zoom, zoom_out, flip_x/y, rotate, drop, swing, pop, bounce_in, none
Независимые постоянные эффекты контейнера, header, title, description, параметров и иконки: pulse, breathe, blink, glow, neon, shimmer, float, bounce, shake, wobble, heartbeat; у иконки дополнительно spin и spin_reverse
Настраиваются скорость, задержка 0–2000 мс, отдельное свечение текста и иконки
Параметры автоматически помечаются для отдельной анимации после Localization
Каталог keyframes общий для генератора native CSS и Preview; генератор проверяет лимиты панелей и классов
