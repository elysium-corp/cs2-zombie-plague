# Подсказка покупки патронов

`Shop.Core` публикует `Shop.Ammo.Empty`, когда у активного зарегистрированного
оружия человека магазин и резерв равны нулю. Проверка выполняется каждые 250 мс
на игровом потоке, без запросов к БД. Нужен доступный оффер с настроенными
ценой и количеством патронов. Недостаток денег не скрывает подсказку.

Баннер показывается один раз за эпизод, по умолчанию на 6 секунд. Длительность
задаётся в CMS. Пополнение патронов, смена оружия, смерть, заражение, открытие
магазина или меню снимают видимые и ожидающие экземпляры только у этого игрока.
Успешная покупка по E закрывает подсказку сразу; остальные изменения — в течение
250 мс. После нового расходования патронов подсказка может появиться снова.
Повторного звука и анимации на каждом тике нет.

## Настройка во Flute CMS

Обновить ElysiumAdvertisements до 3.1.0 вместе с серверными изменениями.
Открыть `/admin/elysium/advertisements/banners?tab=plugins&plugin=Shop.Core`,
выбрать сервер и событие «Закончились патроны».

- Шаблон: `Notifications.Ammo`, иконка `key_e`, положение `bottom_right`
- Ключ описания: `Notifications.Shop.Ammo.Empty` — «Купить патроны»
- Ключ и переводы редактируются через обычный выбор Localization
- Дизайн, иконка, размеры, эффекты, звук, позиция и длительность меняются
  существующим конструктором баннеров
- Доступны параметры `{product}`, `{product_id}`, `{price}` и общий контекст
- Применить переводы командой `localization_reload`, затем оформление `ads_reload`

Миграции добавляют переводы ru/en/de/pl, шаблон и правило через `ON CONFLICT DO
NOTHING`: ранее сохранённые значения администратора не перезаписываются.
JSON fallback Localization также содержит новые переводы.

## Обновление ресурсов

Сначала обновить и применить миграции Localization.Core, затем Advertisement.Core.
Установить CustomHud.Core, Shop.Core и общие API из одного runtime-пакета.
Новые версии: Localization 1.8.0, Advertisement 3.2.0, CustomHud 1.5.0, Shop 1.10.0.

Для VPK нужны **иконка и обновлённые layout/CSS** из
`CustomHud.Core/resources/hud/messages/content/panorama`:

- `images/custom_game/elysium/banners/key_e.svg`
- `layout/custom_game/elysium_messages_v4_r3.xml`
- `styles/custom_game/elysium_messages_v4_r3.css`

Скопировать дерево `content` в аддон Workshop Tools, скомпилировать ресурсы и
обновить VPK. XML обращается к
`s2r://panorama/images/custom_game/elysium/banners/key_e.vsvg`.
SVG для игры сохраняет геометрию приложенного файла; обводка преобразована
в белые залитые контуры, совместимые с имеющимся генератором Panorama.
CMS хранит исходный SVG и окрашивает его через существующую маску preview.

## Проверка в игре

1. Выдать человеку оружие с доступной покупкой патронов и израсходовать весь запас
2. Проверить иконку E и текст снизу справа, затем купить патроны по E
3. Повторить с двумя игроками: покупка одного не убирает подсказку другого
4. Проверить смену оружия, смерть, заражение, открытие магазина и переподключение
5. Сменить язык и ключ/дизайн в CMS, применить настройки и повторить проверку

Компиляция Workshop Tools и игровая проверка обязательны после обновления VPK.
