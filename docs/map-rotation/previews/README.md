# Превью MapRotation

Актуальное интерактивное превью доступно в редакторе MapRotation в Flute CMS: номинации, голосование и результат. Оно использует текущую палитру Elysium, количество карт, настройки ориентации и масштаба.

Статические HTML/PNG ранней версии и их фикстуры удалены: они показывали прежнее фиолетовое оформление с шестью слотами и больше не соответствовали XML/CSS. Они доступны в истории Git, но не являются эталоном новой версии. `scripts/hud-preview/render-menu.py` и `capture.mjs` оставлены как сообщения об отмене прежнего генератора, чтобы старые команды не создавали неверные изображения.

Браузерное превью не доказывает совпадение с Panorama. Проверка в игре требует компиляции Workshop Tools и реальных скриншотов CS2. Состав ресурсов и сценарии проверки: [MapRotation.Core/README.md](../../../MapRotation.Core/README.md#ресурсы-меню).
